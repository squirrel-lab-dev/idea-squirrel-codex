## 五个入口，各做一件事

| 页面 | 用途 | 点击路径 |
| --- | --- | --- |
| 总览 | 日／周／月的会话与记录统计 | 总览 → 选择时间范围；继续旧会话不等于新建 |
| 记录 | 选会话，确认新消息有没有记上 | 记录 → 核对名称 → 查看原话和记录数 |
| 主题与分析 | 会话总结、主题走向、辅助树图 | 主题与分析 → 会话总结／主线图／树状图 → 点条目核对原话 |
| 点子篮 | 已整理点子和引用依据 | 点子篮 → 查看清单／查看原话；可反馈“不对”或“重复了” |
| 提问反馈 | 整体梳理、问题优先级、局部建议 | 提问反馈 → 查看或生成整体梳理 → 点问题查看依据与局部建议 |

### 主题线：看讨论怎么走，不给人打分

![主题线与右侧原话，虚构测试示例](docs/images/topic-demo.png)

行是主题，列是用户原话组；实心点是主要主题，空心点是也涉及的主题。连线换行表示主题变化，**不等于偏题或有进展**；灰色是尚未判断，不代表不好。点击主题或条目核对已有说明与原话。上图只有一组虚构消息，用来展示布局，不是长会话趋势。

### 提问反馈：先看整场，再处理一个问题

![提问反馈入口与右侧原话，虚构测试示例](docs/images/feedback-demo.png)

上图是尚未生成新版建议时的入口，不冒充已生成结果。成功后按「整体梳理 → 先解决／接着解决／可以暂放 → 局部建议」阅读；提示词可编辑、复制，但不会自动发给 Codex。全部截图来自隔离测试，不含真实用户聊天。

**主题线分批分析和整体建议是两个入口。** 自动整理主题与点子，不会自动更新整体建议；查看旧结果免费，点击「生成整体梳理（一次付费）」才请求模型。

## 第一次用：照着点

1. **下载 → 解压。** 在下载页的 **Assets** 选择 `idea-squirrel-windows-0.2.0-preview-20261016-081017.zip` → 右键「全部解压」。不要选 Source code，不要只拿出 EXE。
2. **打开 → 核对会话。** 双击「点子松鼠.exe」，在 Codex 打开准备讨论的会话，再点击桌面松鼠。核对顶部「当前记录」；不一致就点「切换会话」，按名称选择，不用填 ID。
3. **配置自己的 Key。**「主题与分析」→ 展开「模型连接设置 · 小米 MiMo」→ 输入 Key →「加密保存密钥（免费）」。保存不调用模型，也不保证密钥有效。
4. **开始记录与分析。** 当前会话正确时点「开始记录并自动分析」；切换时点「切换到所选会话并自动分析」。这两个按钮允许后续付费分析。回 Codex 聊天，在「记录」页检查是否记上。
5. **看结果。** 看「主题与分析」和「点子篮」。需要提前整理，可点「立即整理一次（主题线＋点子）」，计入额度。需要整体建议，再去「提问反馈」单独生成。
6. **停止。** 点「停止记录和分析」→ 核对记录已停止、API 已关闭。彻底退出：右键松鼠／托盘 →「退出程序」。**收起、关闭面板不等于停止。**

启动默认停止。若看到「恢复本地记录（不调用 API）」，它只恢复记录，不恢复分析；先看失败原因，不连点付费重试。[更多点击步骤与故障说明](docs/桌面版图文指南.md)

## 费用与分批规则

| 操作 | 是否调用模型 |
| --- | --- |
| 看数量、读旧图、刷新已有建议、保存 Key、补读历史、只恢复本地记录 | 不调用 |
| 自动分析、立即整理、生成整体建议、主动重试 | 请求小米 MiMo，可能计费；相同资料已有建议缓存可复用 |

满 **15 条待整理消息**触发，包含用户发言和 AI 正式回复，不是要求你发 15 个问题。每批最多 15 条、最多 6 条用户消息，长消息缩小批次；成功后至少间隔 2 分钟处理积压。失败保留旧图、关闭 API，不自动重试。

常规每轮上限 **100 次**，失败也计次，重启不清零。停止后不发起新请求，已送达服务商的部分仍可能收费。软件不提供免费 Key，不内置作者密钥。

## 边界与隐私

- 不自动跟随新会话；默认读取开启后的新消息，旧历史需主动补读。补读只入库，不等于已经 AI 分析。
- 建议可能只覆盖部分记录，模型可能误判。核对范围、引用和原话，不把 AI 自称完成当验收。不读取隐藏思维链，不评判用户能力。
- 记录、配置和加密密钥在 `%APPDATA%\点子松鼠`；主动分析会把所选素材发给小米 MiMo。不要上传这个目录、日志或密钥。
- 266 项离线测试和隔离桌面测试通过，不代表所有电脑和真实模型效果已验收。遇到系统提示先核对来源，不关闭安全防护。
