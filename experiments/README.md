这里原样保留旧原型的 hook 记录脚本供审查，不属于 `plugins/ai-behavior-reviewer` 安装内容。

没有把 hooks 配置注册到默认插件；没有承诺宿主支持这些事件。`hooks.json` 中的路径面向原型插件布局，不能直接复制到当前发行版使用。

已知风险：

- 保存整个事件，可能记录敏感提示词和本地路径。

- 停止移除标记，但已开始的写入仍可能完成。
- 带空格的脚本路径、环境继承及事件格式未完成客户端验收。

现阶段不向普通下载者提供“一键开启监控”。如需恢复这条路线，应先完善数据最小化、停止状态和隔离测试，再明确授权。
