# 点子松鼠 · Codex 会话复盘

**把讨论的主线找回来，让建议有依据。**

一个按需使用的 Codex 技能插件：从你提供的对话中，整理目标、主题变化、纠正、决定和下一步，并提供具体的提问建议。

**版本：`0.1.0-preview.1` · 私有验收准备版 · 尚未完成真实客户端安装验收。**

[开始使用](使用指南.md) · [功能与边界](功能说明.md) · [五分钟示例](../examples/虚构会话.md) · [验收清单](验收清单.md) · [隐私说明](隐私与费用.md)

## 解决什么问题

与 AI 聊久了，容易忘记最初的目标、已经决定了什么，或者反复解释同一件事。点子松鼠帮助你回看这些内容，不给用户打分，也不把正常换话题直接认定为跑偏。

| 你想知道 | 插件帮助你整理 |
| --- | --- |
| 这段讨论在解决什么？ | 原始目标、主题分支和变化 |
| 哪句话被理解错了？ | 用户纠正、对应回复和原话证据 |
| 接下来还缺什么？ | 已作决定、待办与未解决事项 |
| 我应该怎么问？ | 目标、背景、限制与验收方式的改写建议 |

## 第一次使用

1. 按[使用指南](使用指南.md)添加本仓库中的插件，并在新任务中确认技能可用。
2. 提供一小段可分享的对话，或使用仓库的[虚构示例](../examples/虚构会话.md)。
3. 请求：**“请使用 conversation-review 复盘这段对话，整理主线、纠正和下一步，每项附消息编号。”**
4. 对照原话检查结果。没有证据的完成情况应写“不确定”，而不是猜测。

本插件不需要填写 MiMo API Key；复盘由宿主 Codex 模型处理，可能使用 Codex 额度。

## 与桌面松鼠有什么不同

本仓库是 **Codex 插件**，不是桌面 App，也不是 ChatGPT 网页扩展。

- 本版有：会话复盘技能、提示词结构建议、虚构验收材料。
- 本版没有：浮动人偶、主题线网页、自动点子计数、日周月统计、实时读取所有任务。
- 旧事件记录脚本保存在 `experiments/`，不属于默认安装的插件，不自动运行；不能当成已验收的实时采集功能。

松鼠图片用于插件标识，不代表会出现可交互的桌面宠物。更多边界见[功能说明](功能说明.md)。
