# 验收清单

验收对象：本仓库 `0.1.0-preview.1`，不是桌面 App。

## A. 不调用模型的检查

- [ ] 插件清单校验通过，图标和技能文件存在。
- [ ] marketplace 中的相对路径指向正确插件。
- [ ] README 和文档的本地链接没有断链。
- [ ] 默认插件没有 hooks、MCP、API Key 或外部调用脚本。
- [ ] 仓库不包含真实会话、事件文件、浏览器配置或安装包。
- [ ] 示例明确标注为虚构。

运行：`node --test tests/repository.test.mjs`。这里只检查打包与文档，不代表客户端已安装。

## B. 客户端验收（需要实际操作）

- [ ] 能添加仓库目录，没有覆盖其他插件来源。
- [ ] 列表中能找到“点子松鼠 · 会话复盘”。
- [ ] 能安装、启用，并在新任务中选择 `conversation-review`。
- [ ] 安装后没有自动开始采集、发消息或询问 MiMo Key。
- [ ] 停用后不再作为可用插件运行。

## C. 效果验收（会使用 Codex 模型额度）

使用 [虚构会话](../examples/虚构会话.md)：

- [ ] 识别目标是采购清单，不是完整装修。
- [ ] 把 U2 对 A1 的纠正标出来，并核对 U1 已经提过范围。
- [ ] 不把 U3 的预算约束误判为偏题。
- [ ] 不声称东西已购买、价格已验证或房间已完成。
- [ ] 建议具体且不改变原目标。

## 发布判断

A 通过：仅表示静态准备完成。B 通过：仅表示这个已测客户端能安装。C 通过：仅表示这个虚构样例通过，不证明普遍准确性。

记录系统、Codex 版本、测试日期和实际结果。未通过项保持未通过，不用其他软件的测试数量替代。
