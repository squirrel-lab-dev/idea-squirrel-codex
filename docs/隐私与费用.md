# 隐私与费用

## 默认插件

- 由你主动提供需要分析的材料，不附带作者的聊天数据。
- 技能由宿主 Codex 模型使用，不承诺离线推理或完全本机处理。请按你的账号、组织要求决定能否发送材料。
- 插件没有作者遥测、登录服务器、数据库或自动回传接口。
- 不需要填写 MiMo API Key，不调用作者的额度。Codex 的模型处理仍可能使用你的账号额度。
- 不保证永远免费，不声明准确价格；以宿主当前计费规则为准。

## 实验脚本

`experiments/hooks` 不在默认插件路径中，不会由本插件清单自动注册。若自行运行，它会把收到的完整事件写入指定本地目录，可能包括提示词与文件路径。请勿上传这些事件文件。脚本本身没有网络请求，但宿主模型不因此变为离线。

## 反馈与研究

下载、Star、Issue 都不等于允许作者读取你的对话。不要在反馈中包含凭据、完整私人日志或第三方隐私。研究参与需要单独说明数据用途、范围、保留时间与退出方式并取得同意；本版没有研究招募或数据采集系统。

## 公开发布前

代码和松鼠图像的许可需另行核对。本私有预览没有选择新的开源许可证。旧原型写有 MIT 字段，但该字段不能代替明确的作者授权与许可文件。
