# 功能与边界

## 本版的实际组成

- 一个 `conversation-review` 技能文件，为宿主模型提供复盘流程。
- 一个 Codex 插件清单，包含名称、维护账号、图标和默认请求。
- 一个仓库级插件目录，指向本仓库内的插件。
- 文档、虚构示例、静态测试以及未启用的历史实验脚本。

这不是独立推理模型，也不是数据分析服务器。输出质量取决于你提供的材料和宿主模型，静态验证不能证明分析效果。

## 输出应回答的问题

1. 用户最初要解决什么，之后是否明确改变目标？
2. 讨论出现了哪些主题、分支、纠正和决定？
3. 纠正对应哪条回复，先前是否已有足够说明？区分“没说”“没照做”“拿不准”。
4. 哪些事项有完成证据，哪些仍未解决？
5. 下一条提问怎样变得更明确，而不擅自改变用户意图？

应提供原话依据，区分事实与解释；不编造文件、执行日志、费用或成果，不评价用户是否“正常”，不把猜测当诊断。

## 与另一个交付的区别

| 功能 | 本仓库插件 | 桌面松鼠 App |
| --- | --- | --- |
| 提供材料后按需复盘 | 本版目标能力，待用户效果验收 | 另有分析流程 |
| 浮动松鼠与托盘菜单 | 不包含 | 另一个程序的功能 |
| 网页主题线、原文侧栏 | 不包含 | 另一个程序的功能 |
| 增量采集和自动分析开关 | 默认不包含 | 另一个程序的功能 |
| 持久点子计数、日周月统计 | 不包含 | 另一个程序的功能 |
| 小米 MiMo 配置 | 不需要 | 另一个程序自行配置 |

表格不替桌面 App 宣布验收结果，也不说明本插件已经接通该 App。
