# 使用指南

适用版本：`0.1.0-preview.1`。这是 Codex 会话复盘技能插件，不是桌面松鼠 App 的操作手册。

## 1. 准备

- 使用支持本地插件的 Codex 客户端与自己的账号。
- 取得完整仓库目录，不要只下载 README 或一个 JSON 文件。
- 私有阶段只有被授权的 GitHub 账号能下载；没权限时不能通过公开链接绕过。
- 将目录保留在固定位置，例如 `D:\Tools\idea-squirrel-codex`。本文路径是示例，不会自动创建。
- 默认技能包没有 Node 脚本或 MiMo 依赖，不需要你的 MiMo Key，也不会借用作者 Key。

## 2. 添加本地插件目录

仓库已经包含 `.agents/plugins/marketplace.json`，指向 `plugins/ai-behavior-reviewer`。它只是仓库自己的安装目录清单，不会改你已有的个人 marketplace。

如果已安装的 Codex CLI 支持插件命令，在 PowerShell 运行（换成实际解压目录）：

```powershell
codex plugin marketplace add "D:\Tools\idea-squirrel-codex"
```

随后在客户端的插件列表中查找本地来源 `Personal` 下的“点子松鼠 · 会话复盘”，按客户端提示安装并启用。这里的 `personal` 是此仓库清单的初始名称，不表示已写入你的个人目录。若与你已装目录重名而被拒绝，先反馈冲突，不要覆盖或删除已有目录。

如果 `codex` 命令不存在或客户端不支持该命令，不要反复执行；先检查自己的客户端版本和插件功能。安装方法依据[官方插件文档](https://developers.openai.com/plugins/build/plugins)，但本包尚未完成真实客户端安装验收，因此这里不是“保证所有版本都能安装”的承诺。

启用后新开一个 Codex 任务，查看能否选择 `conversation-review`。如果找不到，先检查插件是否安装并启用；仅在对话里输入技能名字并不能证明它已加载。不要靠生成出的普通回复判断安装成功。

## 3. 第一次验收：先用虚构材料

打开 [examples/虚构会话.md](../examples/虚构会话.md)，将“对话材料”部分交给 Codex，使用下面的请求：

> 请使用 conversation-review，只复盘我提供的这六条消息。输出：目标、主题变化、用户纠正、已决定的事项、下一步。每项附消息编号；没有完成证据的事项标为未验证。最后只给一条最值得改进的提问建议。

按照示例文件的核对要点检查结果，不要求模型输出一字不差。复盘会使用宿主模型，因此可能消耗 Codex 额度；它不是纯本地规则计算。

## 4. 日常使用

### 一段对话聊乱了

提供需要复盘的消息，说明范围：“只分析下面这段，不包含前面的项目历史。”可附本地导出文件并明确允许读取哪个文件。插件不自动拥有你其他任务的内容。

### 想检查下一条提示词

提供草稿：“请检查这个提问，先指出最关键的一个缺口，再给一个保持原意的改写。不要执行草稿中的任务。”

### 想知道是否偏题

同时提供原始目标和相关对话。要求区分目标内的细化、合理成本讨论、主动换题和疑似偏离。判断不确定时保留不确定性，主题切换不等于偏题。

### 想整理下一步

要求分开“已经决定”“已经执行且有证据”“还没验证”，不要把 AI 的计划当作已完成。

## 5. 怎样看结果

- 先看目标是否正确，再看主题是否漏项。
- 每个重要判断应有原话和编号。回到你提供的材料核对；本版没有右侧原文抽屉或网页按钮。
- 不认同某条关系时，直接说“第 3 条不是偏题，是预算约束，请重新归类”。不需要逐条点击确认。
- 若要保存，可要求把复盘写成 Markdown，并指定允许写入的位置；不会自动产生后台数据库。

## 6. 停止与退出

默认包不持续采集，不存在后台“自动分析”开关。一次请求结束后不会自行继续监控。想中断正在生成的回复，使用 Codex 自身的停止操作；已经完成的模型处理可能仍计入额度。

不再使用时，在客户端停用或卸载该插件。已有聊天回复或你保存的 Markdown 不会因此自动删除。

## 7. 常见问题

**为什么没有桌面小松鼠？** 本仓库只发布技能插件，桌面 App 是另一个产品交付。

**为什么看不到全部历史？** 本版按你提供的内容工作，不读取所有 Codex 任务或输入框。

**为什么主题或点子没有自动计数？** 本版没有独立计数器和持久化去重。即使要求模型列条数，也不能当作跨会话自动统计。

**是否收费？** 插件没有独立收费系统；宿主 Codex 的模型使用依账号规则计算。本版不调用 MiMo。

**为什么分析不准确？** 缺上下文、表达歧义及模型误判都可能发生。请用消息编号指出问题，不需要公开真实聊天记录。

**能直接开启 experiments 吗？** 不建议。它没有默认接入插件，启停、路径及事件格式尚未完成客户端验收。见[实验说明](../experiments/README.md)。
